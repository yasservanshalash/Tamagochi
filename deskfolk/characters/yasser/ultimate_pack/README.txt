# DESKFOLK ULTIMATE GENERATION PACK

Contents

- master_reference_sheet.png
- deskfolk_yasser_modular_character_v1.json
- prompt_library/

Workflow

1. Open prompt_library/complete_prompts/
2. Pick ONE prompt.
3. Attach:
   - master_reference_sheet.png
   - deskfolk_yasser_modular_character_v1.json
4. Copy the selected prompt into your image generator.
5. Generate the sprite sheet.

The JSON is the source of truth for dimensions, pivots, anchors and compatibility.
The reference sheet is the source of truth for appearance.
