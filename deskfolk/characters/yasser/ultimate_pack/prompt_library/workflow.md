# Workflow

1. Attach the modular JSON and master reference sheet.
2. Paste `global/global_prompt.md`.
3. Paste one module file.
4. Specify one variant.
5. Generate a 320×320 transparent PNG.
6. Verify bounds, pivot, palette, outline and pixel density.
7. Save using the naming convention.
8. Trim transparent padding only after generation.
9. Preserve the original full-canvas offset in metadata.
10. Pack trimmed sprites into an atlas using nearest-neighbour filtering.
