# Naming Convention

Use lowercase snake case:

```text
character_slot_variant_angle_version.png
```

Examples:

```text
yasser_right_hand_thumbs_up_front_v1.png
yasser_headphones_around_neck_front_v1.png
yasser_eyes_stoned_front_v1.png
yasser_left_leg_walk_contact_side_v1.png
```

Suggested metadata companion:

```text
same_name.json
```
